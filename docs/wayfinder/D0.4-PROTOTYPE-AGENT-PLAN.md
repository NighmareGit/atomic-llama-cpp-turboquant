## Execution Steps

### Step 1: Environment Setup
```bash
# On romulus node
cd ~/projects/atomic-llama-cpp-turboquant

# Ensure builds exist
bash scripts/romulus-local-build.sh --client-only

# Start RPC docker container
bash scripts/romulus-local-up.sh --rpc-only
```

### Step 2: Run Baseline Test
Execute romulus-local with profiling:
```bash
# From repo root on romulus
export GGML_PIPELINE_PLUS=1
export GGML_PIPELINE_MULTI_BACKEND_SEQ=1
export LLAMA_MTP_ACC_TRACE=1
export GGML_SCHED_TRACE=1
export GGML_RPC_TRACE=1

# Start server with trace enabled
bash scripts/romulus-local-up.sh \
  --model /mnt/models/Qwen3.6-35B-A3B-APEX-MTP-I-Quality.gguf \
  --ts 50,50 \
  --ctx 8192
```

### Step 3: Collect Metrics
Monitor and collect:
- GPU utilization: `rocm-smi` for 7900 XTX, `nvidia-smi` for 3060 Ti
- Event record/wait durations from `GGML_SCHED_TRACE`
- RPC timing from `GGML_RPC_TRACE`
- MTP acceptance from `LLAMA_MTP_ACC_TRACE`

### Step 4: Analyze Patterns
Answer key questions:
1. What is the GPU duty cycle on each device?
2. How do events flow between ROCm and CUDA splits?
3. What is the intra-node RPC latency?
4. Can the current pipeline overlap work across the two GPUs?
