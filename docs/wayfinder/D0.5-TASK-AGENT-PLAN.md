## Execution Steps

### Step 1: Identify Integration Points

**In `llama_context`:**
- Where is `ggml_backend_sched` created?
- Where is `decode` dispatched?
- Where is speculative state managed?
- Where are pipeline flags checked?

**In `ggml_backend_sched`:**
- Where is `pipeline_barrier` called?
- Where is `n_copies` set?
- Where are splits computed?

### Step 2: Define GPipe State

Propose additions to `llama_context`:
```cpp
// GPipe state (when GGML_SCHED_GPIPE=1)
struct llama_gpipe_state {
    int n_stages;           // Number of pipeline stages
    int cur_stage;          // Current stage index
    int microbatch_size;      // Tokens in flight
    std::vector<llama_seq_id> stage_tokens;  // Tokens per stage
};
```

### Step 3: Design Decode Entry Point

Propose `llama_decode_gpipe` vs `llama_decode_classic`:
- Flag check: `cparams.gpipe_enabled`
- State machine: stage advance on completion
- KV handoff: producer-consumer with events

### Step 4: Define Scheduler Touch Points

Propose changes to `ggml_backend_sched`:
- `ggml_sched_gpipe_init()` — initialize pipeline state
- `ggml_sched_gpipe_advance()` — move to next stage
- `ggml_sched_gpipe_event_wait()` — wait for upstream stage
- `ggml_sched_gpipe_barrier()` — synchronize stage boundary

### Step 5: Maintain Path-B+ Compatibility

- GPipe default OFF (`GGML_SCHED_GPIPE=0`)
- Existing `pipeline_barrier` unchanged
- No changes to model loading or KV logic
- Feature flag in `llama_context_params`

## Implementation Seam Design

Write to: `docs/wayfinder/D0.5-implementation-seam.md`

Structure:

```markdown
# D0.5 Implementation Seam Design

## Integration Points

### llama_context additions
- `llama_gpipe_state gpipe;` — new member
- `bool gpipe_enabled()` — helper
- `llama_decode_gpipe()` — new entry point

### ggml_backend_sched additions
- `ggml_sched_gpipe_init(sched, n_stages)`
- `ggml_sched_gpipe_advance(ctx)`
- `ggml_sched_gpipe_wait(split_id)`

## Decode Flow Change

```
llama_decode()
  -> if (gpipe_enabled) {
       llama_decode_gpipe();
     } else {
       llama_decode_classic();
     }
```

## KV Handoff

Based on ADR-0002:
- Producer: stage N writes KV + records event
- Consumer: stage N+1 waits on event before read
- MTP: special case — h_prev from target last layer

## Compatibility

- Path-B+ flags unchanged
- GPipe OFF by default
- No upstream merge conflicts expected
```
